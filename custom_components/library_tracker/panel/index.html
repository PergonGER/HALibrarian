Library Tracker

Mit Home Assistant verbinden

Dieses Panel läuft in einem iframe und verbindet sich direkt über die WebSocket-API von Home Assistant. Dafür wird einmalig ein Long-Lived Access Token benötigt — pro Gerät/Browser einmalig einzurichten (der Token wird nur lokal in diesem Browser gespeichert, nicht auf dem HA-Server).

  1. Profil → Sicherheit öffnen
  2. Ganz unten unter "Long-Lived Access Tokens" auf "Token erstellen" klicken, einen Namen vergeben (z. B. "Library Tracker")
  3. Den angezeigten Token-Wert sofort kopieren — er wird danach nie wieder angezeigt
  4. Zurück zu diesem Panel wechseln, Token unten einfügen und auf "Verbinden" klicken

Wert verloren oder auf einem neuen Gerät? Einfach einen weiteren Token erstellen (Schritt 2) — pro Gerät ein eigener Token ist normal und sogar empfehlenswert, dann lässt sich jedes Gerät einzeln widerrufen.
