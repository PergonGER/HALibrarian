Mit Home Assistant verbinden

Dieses Panel läuft in einem iframe und bekommt daher kein hass-Objekt vom übergeordneten Fenster injiziert. Es verbindet sich stattdessen direkt über die WebSocket-API von Home Assistant. Dafür wird einmalig ein Long-Lived Access Token benötigt (Profil → Sicherheit → Long-Lived Access Tokens erstellen). Das Token wird nur lokal in diesem Browser gespeichert.
